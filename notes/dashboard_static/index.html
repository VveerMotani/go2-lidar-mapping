LiDAR mounting

  
—

  
Where the XT16 sits relative to base_link. Read
     from the server so the conversion, the exporter and this page cannot
     disagree about it.


  
Shared defaults

  
—

  

  
Your settings live in this browser. Saving them writes a copy
     on the server, which is what a browser that has never been here starts
     from — a new laptop, a phone, or this one after clearing site data.
     It never overwrites choices already made in a browser.


  
Demo mode

  

  
A read-only view for a wall screen or a visitor: bigger, and
     with nothing clickable that could move the robot or delete a recording.
     Press Esc to leave. It is the same page, so it can never fall
     out of step with this one.
